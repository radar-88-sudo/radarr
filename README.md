# pw-silhouettes (vendored)

Prebuilt spritesheet from https://github.com/plane-watch/pw-silhouettes,
tag `20260908`. Licensed CC BY-NC-SA 4.0 (see LICENSE) - non-commercial
use only, keep attribution if you redistribute.

- `spritesheet.png` - 576x2448 grid of 72x72px aircraft silhouettes
  (white fill / black stroke, recoloured at runtime by the radar page).
- `spritesheet.json` - maps ICAO type designators and ADS-B emitter
  categories to cells in the sheet (see `airframeToSprite` /
  `genericToSprite` / `sprites`).

To refresh: pull the latest `spritesheet.png`/`spritesheet.json` from
that repo's GitHub Releases and drop them in here, same filenames.
